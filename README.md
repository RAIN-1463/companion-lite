# Companion Lite

> 一个单文件、纯本地的 AI 陪伴客户端。
> 第一次打开会让你填：**她是谁 → 什么世界 → 你是谁 → 几条规则**。
> 不需要向量库、不需要 Embedding 服务；中文对话原话检索 p50 约 14 ms（本地 CPU）。

单进程、零框架、单页界面。所有数据都在本机一个目录里，拷走就能用。

---

## 它是什么 / 不是什么

**是**：一个能长期陪一个角色的本地客户端。人设、记忆、关系都在你自己硬盘上。

**不是**：不是云端服务，不是多角色聊天室，不是成品虚拟人。API 调用仍然会把你和她的对话发给你选择的模型厂商——这一点它改变不了，但会尽量少发。

## 快速开始

### 用打包好的 exe（Windows）

1. 解压到一个空目录
2. 双击 `启动.bat`
3. 浏览器打开 `http://127.0.0.1:8899`
4. 四步向导 → 填 API Key → 开始聊

### 从源码跑

```bash
pip install jieba          # 唯一依赖（中文分词）
python app.py              # → http://127.0.0.1:8899
```

### 配置模型

设置里填 **API 地址 / Key / 模型名**，任何 OpenAI 兼容接口都行：

```
DeepSeek   https://api.deepseek.com          deepseek-chat
OpenAI     https://api.openai.com/v1         gpt-4o-mini
本地 Ollama http://127.0.0.1:11434/v1        qwen2.5:7b
vLLM       http://127.0.0.1:8000/v1          你部署的模型
```

## 导入已有聊天（任意平台）

设置 → **导入对话**，三种方式：

| 来源 | 适用 |
|---|---|
| **粘贴** | 直接从任何 App 复制聊天，格式 `我：…` / `她：…` 或纯对话 |
| **QQ 导出 txt** | 一行「时间 昵称」做头，下面是内容 |
| **通用 jsonl / json** | `{"role","content"}` 或 `{"is_user","mes"}` 等常见字段 |

流程：**先预览**（看前 20 条解析对不对）→ **再导入**（重复消息自动跳过）。

也支持从 SillyTavern 迁移：设置 → 从酒馆导入，填酒馆目录后自动找角色卡 / 世界书 / 聊天。

## 记忆怎么工作

```
你发一句话
  → 中文分词 + 词频筛词 + 日期解析
  → FTS5 检索（7 天分区，新到旧，够数即停）
  → 分数边际不够时扩展同义词再找（级联）
  → 取若干条原话，带日期，插在提示词【尾部】
  → 前缀不变，保住 prompt cache
```

另有：

- **日摘要**（每 40 条压缩一次，带绝对日期）
- **事实库**（偏好 / 状态 / 规则，带遗忘曲线）
- **时间轴**（她记得你不在的那段时间）
- **旧摘要检索**（问久远的事时，翻历史摘要而不只是回忆最近）

## 数据在哪

```
data/
  persona.md  canon.md  world.md  user.md  rules.md   人设五件套
  cond_rules.json                                     条件守则（关键词触发）
  setup.json                                          向导原始内容
  config.json                                         API Key（.gitignore 已排除）
  memory.db                                           消息 + 检索索引
```

**备份 = 复制整个 `data/`。** 没有浏览器存储，没有云端。

## 已知限制（先说实话）

| 限制 | 说明 |
|---|---|
| 短词检索 | FTS5 用 trigram，1–2 个汉字的查询命中不稳（如「腰」），计划用 bigram + LIKE 兜底 |
| 事实写入 | 目前是追加式，尚无去重 / 冲突检测；重复事实可能出现 |
| 长对话 | 人格会随对话变长轻微漂移，暂无自动锚点回读 |
| 多用户 | 只服务单机单用户 |
| 打包 | exe 约 40 MB（含 jieba 词典） |

## 明确不做

| 不做 | 原因 |
|---|---|
| 向量 / Embedding | 几千条对话下 FTS5 更快更准，还不用多装服务 |
| 多角色 / 群聊 | 这是一个人的应用 |
| 浏览器存储 | 手机清缓存就丢，备份困难 |
| 云同步 | 数据只在本机 |
